📐 Core Financial Logic & Formulas

  • Available Balance: (Total Savings + Total Interest) − Active Loans Outstanding
  • Monthly Interest: (Outstanding Principal × Monthly Rate 2%) ÷ 100
  • Monthly Target: Total Active Members × Contribution per Share (₹1,000)
  • Member Order: Strictly ascending numerical sort by Member ID (M-1 to M-364)

⚡ Software Stack & Data Layer

  • Frontend: React 18, Vite, Tailored Devanagari Typography & CSS Grid
  • Mobile: Flutter Dart Architecture matching Web Business Invariants
  • Cloud Database: Google Cloud Firestore (Collections: groups/chhatrapati_group_001)
  • Security: Firebase Authentication, Role-Based Access Control (RBAC)
